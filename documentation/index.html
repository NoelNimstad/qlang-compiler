Qlang documentation

Q (pronunced Queue) is a superset of the C programing language with some additional features (such as immutability by default, @ modifiers and a module system) which then compiles back down to C. This website uses the font Fira Code for ligatures because they look awsome. Non-ligaturized versions of operators and such are placed within parantheses if they look too different from their ligaturized version.
